# 物联网后台 · 安装与使用说明（v1.0）

## 一、基本信息
- **应用名称**：物联网后台
- **版本**：1.0
- **平台**：Android
- **默认账号**：admin
- **默认密码**：123456

## 二、安装方法

### 方式一：直接安装 APK（推荐普通用户）
1. 将 `app-release.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 在手机上打开该文件，若弹出“禁止安装未知应用”，按提示允许本次安装。
3. 点击「安装」，完成后桌面出现「物联网后台」图标即成功。

### 方式二：Android Studio 运行（开发者）
1. 安装 Android Studio，打开本项目根目录。
2. 连接手机（需开启 USB 调试）或启动模拟器。
3. 点击 Run 按钮编译安装。

## 三、首次使用
1. 打开 APP，输入账号 `admin`、密码 `123456` 登录。
2. 首次登录后，建议到「我的 → 账号与密码」修改密码。
3. 如需连接真实硬件：进入「我的 → OneNet 平台配置」填入产品 ID / 设备名 / Token，再到「数据模型」绑定传感器标识符。
4. 不配置云平台也能用：未登录云账号时显示固定默认数据，不会再随机乱跳。

## 四、主要功能
- **监控大盘**：温度 / 湿度 / 烟雾浓度 / 水位等传感器实时显示，含 24 小时折线图。
- **设备远程控制**：LED 亮度、距离阈值等滑块拖动即自动下发；排风扇、报警灯、照明灯、蜂鸣器、电磁阀等开关控制。
- **实时视频**：配置视频流地址后查看监控画面。
- **历史数据**：表格查看并导出 CSV，可一键分享到微信 / 用 Excel 打开。
- **异常报警**：数值超过设定阈值时自动记录。
- **设置**：云平台配置、首页标题、视频地址、主题、账号密码、清除缓存。

## 五、更新说明（v1.0）
- 正式定名「物联网后台」，安装后桌面与系统显示此名称。
- 控制页滑块改为**拖动即自动下发**，移除多余的「下发」按钮。
- 未连接云账号时数据固定显示，不再随机乱跳。
- 统一卡片布局：控件名横排、滑块占满宽度、不再溢出边框。
- 清理作者署名信息，版本标记为 1.0。

## 六、安全提示
- 默认密码 `123456` 仅用于首次登录，请尽快修改。
- OneNet Token 属敏感凭证，请勿泄露给第三方。
